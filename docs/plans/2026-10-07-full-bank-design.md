# 行测全科与申论题库

用户要求将当前只有数量关系的本机刷题入口扩展到行测全科和申论。

沿用本机只读 SQLite 服务，读取题型索引与材料库；去重后按考试科目、科目和细分题型筛选。课程中的数量关系同类题入口继续使用原有文字完整题池。完整刷题页保留题干、选项、解析图片和关联资料，HTML 只允许内容标签及 HTTPS 图片，图片失败提供缺失提示。

行测支持单选、多选和判断题，提交后记录作答，错题可返回原题。申论显示已收录同卷资料及材料完整性提示，提供作答、自动保存、字数统计、导出和复盘；主观题不自动判对错。AI 答疑增加各科和申论方向，允许携带完整材料，缺材料时不生成伪造点评。

验证使用临时数据库覆盖六科、材料关联、含图题、单多选和申论。浏览器测试使用 localhost 来源隔离用户在 127.0.0.1 的学习记录及 Key。
